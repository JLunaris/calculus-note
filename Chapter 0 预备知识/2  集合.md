
# 集合

### 定义

集合由元素组成，集合中的元素具有如下特征：

1. **确定性**：要么在，要么不在这个集合
2. **互异性**：不存在相同的元素
3. **无序性**：$\{1,2,3\}$ 和 $\{3,2,1\}$ 是同一个集合

### 描述方法

1. **列举法**：例如 $\{1,2,3\}$
2. **描述法**：格式为 $\{元素|元素的特征\}$

> 案例：
> - 数集：$\{x\in \mathbb{R}\mid x^2-x+1=0\}$
> - 点集：$\{(x,y)\mid y=x+1\}$
> - 其他：$\{字符串|长度大于3的\}$

3. **区间表示法(只针对数集)**：例如 $(1,2]$
4. **符号表示法(只针对数集)**：自然数集 $\mathbb{N}$，整数集 $\mathbb{Z}$，有理数集 $\mathbb{Q}$，实数集 $\mathbb{R}$，复数集 $\mathbb{C}$

### 关系

##### 元素 与 集合 的关系

- 属于：$a\in A\ \Longleftrightarrow \ \exists x\in A,\ x=a$
- 不属于：$a\notin A \ \Longleftrightarrow \ \forall x\in A,\ x \not ={a}$

> Q：**元素**$(1,2)$是否属于**集合**$(0,3)$?  
> A：作为元素的“$(1,2)$”本身不是数，而$(0,3)$是一个数集，因此不属于。

##### 集合 与 集合 的关系

- **包含于**：$A \subseteq B \ \Longleftrightarrow \ \forall x \in A, \ x\in B$
  此时称A是B的**子集**。
- **真包含于**：$A \subset B \ \Longleftrightarrow \ \begin{cases}\forall x \in A, \ x\in B \\\exists x_0 \in B, \ x_0 \notin A\end{cases}$
  此时称A是B的**真子集**。
- **相等**：$A=B \ \Longleftrightarrow \ \begin{cases}A \subseteq B \\B \subseteq A\end{cases}$

> 【例】$A=\{x\mid x=2k+1,k \in \mathbb{N} \}$，$B=\{x\mid x=2k-1,k \in \mathbb{N} \}$，求证 $A\subset B$。
> 
> 证明：$A \subset B$ $\iff$ $A \subseteq B \ 且\ A \not ={B}$ $\iff$ $A \subseteq B \ 且 \ B \not\subseteq A$
> 
> 先证 $A \subseteq B$：只要证 $\forall x \in A, \ x\in B$。
> $\forall x \in A$，$x=2k+1$（$k\in\mathbb{N}$）。令 $2k+1=2t-1$，解得 $t=k+1\in\mathbb{N}$。因此 $x\in B$。
> 
> 再证 $B \not\subseteq A$：只要证 $\exists x_0\in B,x_0\notin A$。
> 取 $x_0=-1$，显然 $x_0\in B$，$x_0\notin A$。

### 空集

**空集**就是元素个数为0的集合，记作 $\emptyset$。

规定：空集是任意集合的子集，是任意非空集合的真子集。

### 运算

- 并：$A\cup B=\{x \mid x \in A \ 或\ x\in B\}$
- 交：$A\cap B=\{x \mid x \in A \ 且\ x\in B\}$
- 补：$\complement_U A=\{x \mid x \in U \ 且\ x\notin A\}$
